# KorisLab prototype logo sources

Retrieved 2026-10-10. Source files are preserved, with visible alpha bounds normalized at render time. All 21 clubs appearing in the six supported league/season snapshots have their own logo. Club names, cities and image source URLs are recorded in `source/team-logos.json`. These are current club marks, also used on historical season views.

- Men's league logo: https://basket.fi/korisliiga/ → https://basket.fi/wp-content/uploads/2026/01/logo_korisliiga.png
- Club logos: official Basket.fi PENA teams API, linked by https://basket.fi/sarjat/sarjat/korisliiga/tilastot/ and https://basket.fi/sarjat/sarjat/naisten-korisliiga/tilastot/. Original images hosted at images.dc.connect.sportradar.com.
- Kouvottaret (missing from PENA): https://www.kouvottaret.fi/ → https://www.kouvottaret.fi/wp-content/uploads/2021/09/cropped-cropped-cropped-kouvottaret_logo_tp-300x247.png
- API competition IDs: men `f874dc00-e92f-5090-beb3-e47826cda185`, women `3b2332fd-e6d2-5154-ab94-43756f6e651d`; seasons 2024–25, 2025–26 and 2026–27.
