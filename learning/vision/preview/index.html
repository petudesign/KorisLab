4. Mistä väripäätelmä syntyy?

Klikkaa paitakuvaa: oranssi rajaus näyttää, mistä kohdasta värit on laskettu. Numerot ovat tämän ruudun havaintonumeroita; ne eivät seuraa samaa henkilöä eri ruuduissa.

Tämä on ensimmäisestä ruudusta sovitettu värisääntö. Harmaa paita, peittyminen tai taustan väri voi johtaa virheeseen. Epäselvä ei tarkoita tuomaria: myös oikea pelaaja voi jäädä siihen ryhmään.

Mitä koodi tekee?

width = x2 - x1
height = y2 - y1

crop_box = (
    x1 + width * 0.25,
    y1 + height * 0.20,
    x1 + width * 0.75,
    y1 + height * 0.50,
)
shirt = image.crop(crop_box)
Selkeytetty ote: Python-tiedostossa koordinaatit pyöristetään ja rajataan kuvan sisälle.

Mitä tästä opimme?

Laatikosta otetaan keskimmäiset 50 % leveydestä ja ylhäältä 20–50 % korkeudesta. Tavoitteena on saada mukaan paita, mutta välttää pää, shortsit ja tausta.

Väreistä lasketaan osuudet HSV-väriavaruudessa: sävy, värikylläisyys ja kirkkaus. Näytetyt väriosuudet eivät ole mallin varmuuksia.

Värisäännöt luokittelevat vihreän, valkoisen tai epäselvän. Ne eivät vielä opi peliasuja eikä tässä seurata pelaajia ruudusta toiseen.
