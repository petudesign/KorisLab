# KorisLab — motion study 01

KorisLab case-study motion experiments. 1920 × 1080, 60 fps, Finnish, silent.

Open the local Studio at `http://localhost:5180/KorisLab-Case` and press Play.

## Direction

The primary composition is a 18.8-second advertisement with eight scenes, 1920 × 1080, 60 fps and no audio yet. Durations follow the action and reading needs rather than a uniform cadence. A 0.1-second fade connects each cut.

- 0.00–1.40: Hook.
- 1.30–4.90: Search — natural uneven typing from 0.25 to 1.35 seconds within the scene, submit feedback, then the answer appears at 1.70 seconds and stays readable.
- 4.80–6.80: Player leaders.
- 6.70–9.30: EBT offensive-rebound insight — slower count and chart reveal.
- 9.20–11.20: Full-court shot map.
- 11.10–13.40: Game scoring progression — chart draws over 1.05 seconds.
- 13.30–16.10: Matchup Lab — the two profiles form sequentially before the reading hold.
- 16.00–18.80: Benefit and call to action.

All animations derive from Remotion frames. The original 10-second, three-scene study is preserved as `KorisLab-Study`. The advertisement is `KorisLab-Case`.

Cal Sans and Inter retain the app's hierarchy, with Array for the opening accent. Orange marks data; green marks the brand and made shots; blue is the comparison color. Static dither stays confined to the season insight.

## Data

The snapshot comes from the app's verified Women's Korisliiga 2025–26 matches. Both clubs have 24 games. Player leaders use at least eight games and 120 total minutes. The imported shot log is checked against its verified match before it is used. EBT ORB% is 40.0%; the pooled league figure is 34.2%. Radar values use the same shared league-rank calculation as Matchup Lab. These are descriptive statistics, not tactical or causal claims.

`src/data.ts` is generated by `scripts/prepare-assets.mjs`, using the existing app's `matchupRecords`, `matchupStats` and `matchupRadar` modules. Fonts and logos are copied from the app's existing assets. Run `pnpm prepare-data` to refresh the snapshot explicitly; it does not fetch live data.

## Editing

The eight advertisement scenes have their own connected compositions under Scenes. Edit their React source or inspect each timeline in Remotion Studio. The main composition is `KorisLab-Case`.

- `pnpm dev --no-open --port 5180`: Studio.
- `pnpm lint`: type and lint checks.
- `pnpm prepare-data`: refresh local assets and snapshot.

The first deliverable is an editable Studio preview. Audio, English version and further scenes can be added after reviewing the motion direction.

## Case-page delivery

The approved Finnish advertisement is exported to `out/korislab-case.mp4` (H.264, 1920 × 1080, 60 fps, 18.8 seconds, no audio track), with `out/korislab-case-poster.jpg` as its still cover. Keep these local delivery files; `out/` is excluded from Git.

For a silent looping case-page embed, upload both files and use:

```html
<video autoplay muted loop playsinline preload="metadata"
  poster="/media/korislab-case-poster.jpg"
  width="1920" height="1080"
  aria-label="KorisLab: haku, pelaajatilastot ja otteluanalyysi">
  <source src="/media/korislab-case.mp4" type="video/mp4">
</video>
```

Size responsively (`width: 100%; height: auto`). Include a pause/play control in the case page and honor reduced-motion preferences by showing the poster until playback is requested. The case page itself is not modified by this export.
